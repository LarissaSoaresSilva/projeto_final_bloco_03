## 📝 Descrição do Projeto

Este projeto faz parte do Bloco 03 do curso de formação da Generation Brasil. O objetivo principal é desenvolver uma aplicação full-stack utilizando Spring Boot no backend e React com Tailwind CSS no frontend. A aplicação permite o gerenciamento de categorias de produtos, incluindo operações de CRUD (Create, Read, Update, Delete).

##

## 🚀 Tecnologias Utilizadas

- **Backend:**
  - Java 17
  - Spring Boot 2.7.5
  - Maven 3.8.6
  - JPA/Hibernate
  - MySQL

- **Frontend:**
  - React
  - TypeScript
  - Tailwind CSS
  - Axios
  - React Router

- **Ferramentas:**
  - Insomnia (para testes de API)

##

## ⚙️ Funcionalidades

- **Backend:**
  - Endpoints para operações CRUD de categorias.
  - Validações de dados.
  - Integração com banco de dados MySQL.

- **Frontend:**
  - Interface responsiva para gerenciamento de categorias.
  - Formulários para criação e edição de categorias.
  - Listagem de categorias com opções de edição e exclusão.
  - Feedback visual para ações do usuário.

##

## 🛠️ Como Executar

1. **Pré-requisitos:**

   - Java 17 instalado.
   - Node.js e npm instalados.
   - MySQL instalado e em execução.
   - IDE de sua preferência (IntelliJ, Eclipse, VS Code).

2. **Clone o repositório:**
```
git clone https://github.com/LarissaSoaresSilva/projeto_final_bloco_03.git
```

3. **Configure o banco de dados:**

- Crie um banco de dados MySQL com o nome desejado.
- Atualize o arquivo `application.properties` com as credenciais do banco.

4. **Execute o backend:**

- Via IDE: execute a classe `ProjetoApplication.java`.
- Via terminal:
  ```
  ./mvnw spring-boot:run
  ```

5. **Execute o frontend:**

- Navegue até o diretório `frontend`:
  ```
  cd frontend
  ```
- Instale as dependências:
  ```
  npm install
  ```
- Inicie a aplicação:
  ```
  npm start
  ```

6. **Acesse a aplicação:**

- O frontend estará disponível em `http://localhost:5173`.
- A API estará disponível em `http://localhost:8080`.
